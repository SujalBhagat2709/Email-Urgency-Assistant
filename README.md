# Email Urgency Assistant

## Overview

Email Urgency Assistant is a Python application that helps users identify important emails by analyzing their subject and message content.

Instead of manually checking every email, the system calculates an urgency score, determines an urgency level, detects a general category, and ranks emails by priority.

## Features

- Analyze Email Content
- Urgency Score
- Critical / High / Medium / Low Classification
- Email Category Detection
- Urgency Reason Detection
- Priority Email Ranking
- Email Summary
